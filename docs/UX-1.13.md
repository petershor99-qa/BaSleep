# BaSleep 1.13 — ночной сон одним тапом и базовое расписание

По обратной связи от 04.11.2026: «почему ночью не делает ночной сон» и
«нет кнопки полного сброса и возврата к базовому расписанию».

## Изменения

- **Ночной «Уснул» классифицируется автоматически**: если бодрствование
  продолжается после 21:00 (и до 06:00), главная кнопка становится
  «Ночной сон» — один тап записывает уход в ночь (фаза NIGHT). Раньше
  получался дневной «Спит», а отдельную ссылку легко было пропустить.
  Классификация по времени нажатия, не автоопределение сна.
- **«Начать заново»** — кнопка полного сброса записи всегда видна на
  главном экране (раньше — только в настройках и пилюлей после 16 ч).
  Сохранена отмена.
- **Базовое расписание в исходном состоянии**: до первого «Проснулся»
  приложение показывает раскрывающийся план-ориентир (подъём 09:00,
  4 сна, ночь 21:35–09:00 — по схеме консультанта), чтобы экран не был
  пустым и цифры были видны сразу.
- Ссылка «Ночной сон (сохранит начало)» осталась только для фазы «Спит»
  (сон, начавшийся до 21:00 и перетёкший в ночь).

## Затронутые правила

SleepEngine не изменён (использованы существующие startNight/startDay);
классификация — на уровне UI. Версия 1.13, versionCode 14. Тесты: 42,
все зелёные.

## Проверки

- :app:testDebugUnitTest — 42 без ошибок; :app:assembleDebug — ок.
- Эмулятор API 35: READY 08:30 → базовое расписание совпадает со схемой

- APK установлен на физический телефон (Reno13 F, USB) с сохранением данных.

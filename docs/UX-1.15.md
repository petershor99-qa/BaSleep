# BaSleep 1.15 — дизайн-переработка и подтверждение записи

Дата: 08.11.2026. По запросам владельца: «дизайн скучный», кнопка-подтверждение,
убрать кружочек, нативная агрегация дня.

## Изменения

- **Запись через подтверждение**: тап по главной кнопке открывает панель
  с уже подставленным временем нажатия; «Записать» — и событие в журнале.
  Кнопки «Исправить время» и «в другое время…» удалены (тот же механизм),
  отмена ошибок — «Отменить».
- **Герой с градиентом**: карточка статуса — вертикальный градиент (день
  сине-индиго, ночь фиолетовый), кнопка — градиентная со свечением (shadow
  spotColor по фазе). Цвет героя и кнопки меняется с фазой анимацией.
- **Карточка «День»** объединила ориентир, план, факт: полоса дня сегментами
  (окна тёмные, сны подсвечены, бегунок «сейчас»), тап по полосе — правка
  начала текущего события; строки «😴 Спать осталось ~X из N», «⏱ до отбоя
  ~Y», кормление-ориентир; блок «Факт» (нормы по факту); «План дальше».
- **Мелочи**: кружочек-иконка над статусом удалён; у «Спит» — дыхательная
  анимация иконки; табличные цифры (tnum) — время не дёргается; виджет —
  цвет по фазе + полоса прогресса этапа; имя ребёнка — настройка.
- Упрощено: убраны дубль-пилюля «Начать новый день» (есть «Начать заново»)
  и лишние кнопки. Fixed crash: weight(0) при записи ровно в момент пробуждения.

## Затронутые правила

SleepEngine не изменён. Версия 1.15, versionCode 16. Тесты: 54, все зелёные.

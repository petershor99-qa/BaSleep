## 2. Исправления по разделу 3

- **3.1 UTC-фикс**: `wakeTod` через `todOf(dayStart, zone)`; остатков epoch
  больше нет. Тест: московский 09:00 → wakeTod 540.
- **3.2 Полночь**: единая относительная шкала nowRel (0..dayLen); 11:53/00:10 →
  737/18; 01:00 → после отбоя, без «34 ч 53 мин». Тесты ×4.
- **3.3 «До подъёма»** из `forecasts`; NIGHT_AWAKE без прогноза — без
  ложного остатка.
- **3.4 Один текущий сегмент** по [relStart, relEnd); границы подъём/сон/
  конец сна/отбой — тест ×4 + цикл по всему дню с шагом 5 мин.
- **3.5 Regress на полосе**: dayBar принимает regress; тест 21:35 → 20:45;
  блок подписан «План дня».
- **3.6 Regress и ночь**: комментарий в forecasts + тест (ночь не растёт).
- **3.7 Ночь**: `nightSleepMinutes` — NIGHT: nightStart→now − все NIGHT_WAKE
  текущей ночи (305 мин в контрольном сценарии, не 40); NIGHT_AWAKE: до
  пробуждения (265); два бодрствования не задваиваются (295); нет nightStart
  → null → «—».
- **3.8 Снимок панели**: RecordSheet(action, label, openedAt) фиксируется при
  тапе; смена минуты не сбрасывает ввод (проверено вживую: открыто в 11:59,
  смена на 12:00 — поля 11|59 целы); guard возвращает ошибку вместо
  молчаливого «успеха».
- **3.9 Минуты**: авто-переход после второй цифры с полным выделением;
  последовательный ввод 09→05 даёт ровно 09:05 (вживую); правка только
  минут работает.
- **3.10 ModalBottomSheet**: imePadding, «Записать» доступен при клавиатуре,
  отмена/назад/dismiss не записывают, при ошибке панель остаётся открытой,
  после записи закрывается. Отступлений нет.
- **3.11 Полоса**: легенда «Фиолетовый — сон / Тёмный — бодрствование»,
  «▲ сейчас», один подсвеченный сегмент с белой рамкой, номера снов сохранены.
- **3.12 Иерархия**: «Факт» сворачиваемый, по умолчанию компактная строка.
- **3.13 Плитки**: «Днём сегодня», «Ночью сейчас»/«Прошлая ночь», «Всего за
  сутки»; «—» при отсутствующей ночи; янтарная подсветка сохранена.
- **3.14 Сдержанность**: свечение 6 dp, маркер статичный (пульсация
  удалена), breathing только у иконки сна, палитра не менялась.
- **3.15 Доступность**: полоса в 48 dp зоне, норм-текст 11 sp, TalkBack
  описание полосы, contentDescription = null у декоративных иконок.

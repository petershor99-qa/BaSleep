- **Ручной ввод времени**: «‹действие› в другое время…» записывает главное

## Актуальная модель v1.13 (приоритет над историческими правилами ниже)

По прямому запросу владельца от 03.11.2026 приложение теперь трекер текущего
состояния с одной кнопкой «Уснул / Проснулся», без журнала и статистики.
Доработки v1.12–v1.13 (04.11.2026):

- **«Начать новый день» (полный сброс записи)**: кнопка в настройках + «Начать
  заново» на главном экране + пилюля при длительности состояния ≥16 ч. Сброс
  → фаза READY, отмена через один снимок undo.
- **Классификация ночи по времени нажатия** (UI-уровень, LiveTracker не менялся):
  фаза AWAKE + локальное время 21:00–06:00 → главная кнопка «Ночной сон»
  (startNight, фаза NIGHT); NIGHT + 06:00–21:00 → кнопка «Начать день»
  (startDay) одним тапом, ссылка «Проснулся ночью» осталась для ночных эпизодов.
- **Базовое расписание** показывается в фазе READY (SleepEngine.build с подъёмом
  из prefs-ключа `wake`) — план-ориентир до первого факта.
- Тикер времени — по границе минуты; повреждённая сессия (`Session.corrupt`)
  показывает предупреждение, а не молчаливый сброс.

- `LiveTracker` в SleepEngine.kt — текущая сессия и прогноз. `SleepEngine`
  оставлен для совместимости и регрессионных тестов старой математики.
- Факты записываются по времени телефона с точностью до минуты. Они НЕ
  ограничиваются возрастными коридорами, длительностью 20–240 мин, шагом 5 мин
  или расчётной ночью. Эти ограничения применимы только к старому калькулятору;
  в трекере возрастная схема ограничивает лишь прогноз будущих окон.
- Исправление: только часы/минуты, последнее прошедшее вхождение этого времени.
  Время позже текущего означает вчера. Не допускается нарушение хронологии.
- `Prefs.live_session` хранит только текущее состояние и один снимок отмены.
  Атомарное сохранение переживает закрытие приложения; история не ведётся.
- На первом запуске трекер ждёт «Проснулся», старые расчётные поправки не
  превращаются в якобы фактический сон. Старые настройки и ключи сохраняются.
- После 21:00 и до 06:00 на главном экране доступен «Ночной сон»; в настройках
  он доступен и раньше. Уже начавшийся дневной сон переводится в ночной с
  сохранением начала. Ночное пробуждение не начинает день автоматически:
  «Уснул» продолжает ночь, «Начать день» начинает день со времени пробуждения.
- Кормления остаются фиксированными ориентирами, ±15 минут не отслеживаются.
- Настройки возраста/схемы меняют только прогноз, записанный факт сохраняется.
- Виджет использует LiveTracker и ту же сессию, что приложение.
- Версия повышается при изменениях, сообщения коммитов по-русски. Прогнать
  старые SleepEngineTest и новые LiveTrackerTest, проверить реальные UI-сценарии.

## Модель правок (v1.8+)

Происхождение правок разделено и НЕ смешивается:

- `Window.manual` — только ручные правки; клэмпятся **на входе**
  `sanitizeAdj` (скрытого запаса за границей коридора не накапливается);
- `Window.comp` — авто-компенсация после факта сна (± до `COMP_MAX` = 15);
- `Window.regime` — режим «Регресс сна» (−`REGRESS_STEP` = 10 всем окнам);
  хранится отдельно (prefs-ключ `regress`) и в `Adjustments` НЕ попадает.

`build(age, plan, wake, adj, regress)` санитизирует правки на входе;
любое изменение UI-состояния проходит через санитайз. Кормления:
`FeedKind` = AT_WAKE / IN_WINDOW / IN_NAP (наезд) / BEFORE_WAKE
(нейтральное «до подъёма», ≤90 мин до подъёма) / AFTER_BEDTIME / NIGHT.

UI: единые векторные иконки `res/drawable/ic_*.xml` (без эмодзи в основном
UI), зоны нажатия от 48 dp, semantics для TalkBack, выбор чипов — «✓»,
длительности в формате «1 ч 20 мин» (`fmtDurHuman`).

## Бизнес-правила (консультант по сну, возраст 3 мес)

Базовая схема «4 сна» при подъёме 09:00: сны 10:25–11:45 (1:20),
13:20–14:40 (1:20), 16:20–17:30 (1:10), 19:15–20:15 (1:00), отбой 21:35,
ночь 11:25, день 4:50, всего 16:15.

- Окна бодрствования: норма 1:15–1:45, жёсткий коридор 1:10–1:50.
- Дневной сон 4–5 ч, ночной 11–12 ч, всего 15–17 ч.
- **Все времена кратны 5 минутам** (шаг любых правок ±5).
- Инвариант: Σбодрствований + Σдневных снов + ночь = 1440 мин (24 ч), ночь =
  остаток суток. Сдвиг пробуждения сдвигает весь день целиком.
- Правки: факт сна (±5.., клэмп 20–240 мин) пересчитывает хвост дня и
  **авто-компенсирует следующее окно** (сон короче → окно короче, до ±15 мин,
  `COMP_MAX`). Ручные правки окон клэмпятся в жёсткий коридор возраста.
- «Регресс сна»: все окна −10 мин (`REGRESS_STEP`), отбой раньше; включается/
  выключается кнопкой, состояние сохраняется.
- Возрастные схемы: 3 мес → «4 сна»/«5 снов»; 4 мес → «4 сна»/«3 сна»;
  5 мес → «3 сна». Коридоры 4–5 мес мягче (см. `SleepEngine.AGES`).
- Кормления: 7 времён по умолчанию 00:00/04:30/09:00/12:00/15:00/18:00/21:00
  (`DEFAULT_FEEDS`), редактируются ±5. Классификация `FeedKind`: AT_WAKE
  (совпал с подъёмом), IN_WINDOW (между снами — норма), IN_NAP (наезд —
  предупреждение), AFTER_BEDTIME (после отбоя, вечернее — «покормить до
  укладывания»), NIGHT (ночное, до полудня — «не будим»).
- Границы фаз «сейчас»: конец сна = уже бодрствование; момент отбоя = ночь;
  подъём = первое окно.

## Неизменяемые требования

1. После любых правок движка: `:app:testDebugUnitTest` зелёный (сейчас 23
   теста — сверяйся с фактическим числом). Сломал инвариант (кратность 5,
   Σ=24 ч, коридоры) — считай багом.
2. Никаких сетевых запросов, аналитики и внешних зависимостей в рантайме.
3. Сохраняется ВСЁ состояние: возраст, схема, время пробуждения, кормления,
   факты снов, правки окон, режим регресса. Смена схемы/возраста сбрасывает
   только факты и правки (новый чистый план).
4. Ключевые цвета UI: фон #0E1118, карточка #161B27, акцент #9BB8FF, ночь
   #C9B8FF, предупреждение #E8C476, кормления #9FD8B4. Кнопки: пружинное
   сжатие + ripple + хаптика; числа меняются «прокаткой» (AnimatedContent).
5. Новые строки UI и экспорта — только по-русски, тон спокойный, без паники.
6. Экспорт дня (`exportText`): секции разделены пустой строкой, формат
   «🍼 09:00 · ⏱ Бодрствование 1:25» / «😴 Сон 1 — 10:25–11:45 (1:20)»,
   итоги в конце с явными подписями («Сон днём … ночью … всего …»,
   «Бодрствование всего …»).
7. Грабли, уже отработанные: `Shape` импортируется из `androidx.compose.ui.graphics`;
   `BackHandler` — из `androidx.activity.compose`; вариативные шрифты
   (`variationSettings`) в этой версии Compose экспериментальны — использовать
   статические начертания; aapt/adb кириллические пути не открывают — копировать
   файл по ASCII-пути перед инспекцией.
